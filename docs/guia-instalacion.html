🤖 Bot de PR Autorización

Guía paso a paso para instalar y configurar el bot en tu computadora

Contenido 1. Requisitos previos 2. Instalación 3. Configurar Telegram 4. Configurar variables de entorno 5. Ejecutar el bot 6. Cómo usar el bot 7. Mantenerlo corriendo (PM2) 8. Solución de problemas

1. Requisitos previos

Necesitas tener instalado en tu Mac:

SoftwareVersión mínimaCómo verificar
Node.js18+node --version
npm9+npm --version
Gitcualquieragit --version

Si no tienes Node.js, instálalo con:

brew install node

2. Instalación

1 Clonar el repositorio 
git clone https://bitbucket.org/tu-org/reclutalia-aws-pr-bot.git
cd reclutalia-aws-pr-bot
2 Instalar dependencias 
npm install

Esto también instala Chromium automáticamente (necesario para la automatización).

La primera vez puede tardar 2-3 minutos por la descarga de Chromium.
3 Copiar archivo de configuración 
cp .env.example .env

3. Configurar Telegram

3.1 — Crear el bot de Telegram

1 Hablar con @BotFather en Telegram

Abre Telegram, busca @BotFather y envía:

/newbot

Te pedirá un nombre y un username. Ejemplo:

  • Nombre: PR Autorización Bot
  • Username: mi_pr_auth_bot (debe terminar en "bot")

BotFather te dará un token como: 7123456789:AAH...

Guárdalo, lo necesitas para el .env.

3.2 — Crear el grupo de Telegram

2 Crear un grupo y agregar el bot
  • Crea un grupo nuevo en Telegram (ej: "PR Autorización")
  • Agrega tu bot al grupo
  • Hazlo administrador del grupo (necesita permisos para leer y enviar mensajes)

3.3 — Obtener el Chat ID del grupo

3 Obtener el Chat ID

Envía cualquier mensaje en el grupo, luego abre en tu navegador:

https://api.telegram.org/bot<TU_TOKEN>/getUpdates

Busca "chat":{"id":-100XXXXXXXXXX}. Ese número negativo es tu TELEGRAM_CHAT_ID.

3.4 — (Opcional) Usar Topics

Si tu grupo tiene Topics habilitados y quieres que el bot solo hable en un topic específico:

  • Envía un mensaje en el topic deseado
  • En la respuesta de getUpdates, busca "message_thread_id": 205
  • Ese número es tu TELEGRAM_TOPIC_ID

3.5 — Obtener tu User ID

4 Obtener tu User ID de Telegram

Habla con @userinfobot en Telegram. Te responderá con tu ID numérico.

Ese es tu TELEGRAM_OWNER_USER_ID (para recibir MFA y alertas por DM).

3.6 — Usuarios autorizados

Solo los usuarios listados en TELEGRAM_AUTHORIZED_USERS pueden aprobar o rechazar PRs. Si alguien no está en la lista, el bot le dirá "No estás autorizado".

Agrega los usernames de Telegram (sin @) separados por coma:

TELEGRAM_AUTHORIZED_USERS=juanalva997,JcLievano,gabrielbarba28,el_chambas3000

4. Configurar variables de entorno

Edita el archivo .env con tus datos:

VariableQué ponerEjemplo
TELEGRAM_BOT_TOKEN Token que te dio BotFather 7123456789:AAH...
TELEGRAM_CHAT_ID ID del grupo (número negativo) -1001234567890
TELEGRAM_OWNER_USER_ID Tu User ID numérico 123456789
TELEGRAM_TOPIC_ID ID del topic (opcional, dejar vacío si no usas topics) 205
TELEGRAM_AUTHORIZED_USERS Usernames de Telegram autorizados (sin @, separados por coma) juanalva997,JcLievano
AWS_LOGIN_URL URL de login de tu cuenta AWS https://upax-reclutalia-dev.signin.aws.amazon.com/console
AWS_ACCOUNT_ID Alias o ID de la cuenta AWS upax-reclutalia-dev
AWS_USERNAME Tu usuario IAM de AWS tu.usuario
AWS_PASSWORD Tu contraseña IAM de AWS TuPassword123!
HEADLESS true = browser invisible, false = ves el browser true
Nunca compartas tu archivo .env. Contiene credenciales sensibles. Ya está en .gitignore.

5. Ejecutar el bot

1 Compilar y ejecutar 
npm run start

Deberías ver:

🚀 Iniciando bot de PR Autorización...
[WS] Servidor WebSocket iniciado en puerto 9876
🤖 Bot de Telegram iniciado, escuchando mensajes...
✅ Bot corriendo. Presiona Ctrl+C para detener.
Si ves ese mensaje, el bot está funcionando. Ahora pega una URL de PR en el grupo de Telegram y verás la solicitud de aprobación.

Primera vez: MFA

La primera vez que el bot intente hacer login en AWS, te pedirá el código MFA por DM en Telegram. Asegúrate de:

  • Tener tu app de MFA lista (Google Authenticator, etc.)
  • Responder con los 6 dígitos cuando el bot te escriba por DM
  • Que el código tenga al menos 20 segundos antes de expirar

Después del primer login, el bot guarda la sesión y no vuelve a pedir MFA hasta que expire.

6. Cómo usar el bot

Flujo normal

  1. Alguien pega una URL de PR de CodeCommit en el grupo
  2. El bot detecta la URL y envía botones: ✅ Aprobar / ❌ Rechazar
  3. Un usuario autorizado hace click en ✅
  4. El bot procesa el PR automáticamente (approve + merge)
  5. Reporta el resultado en el grupo

Comandos disponibles

ComandoQué hace
/statusMuestra si el bot está activo y el estado de la cola
/queueMuestra los PRs en cola
/logMuestra los últimos 5 PRs procesados
/pr <url>Agrega un PR manualmente

Aprobar por texto

También puedes aprobar escribiendo en el grupo:

  • si — aprueba el PR pendiente (si solo hay uno)
  • si #29540 — aprueba un PR específico (si hay varios)
  • no — rechaza el PR pendiente

7. Mantenerlo corriendo (PM2)

Para que el bot se mantenga corriendo aunque cierres la terminal:

1 Instalar PM2 (una sola vez) 
npm install -g pm2
2 Iniciar el bot con PM2 
npm run build
pm2 start dist/main.js --name reclutalia-pr-bot
3 Comandos útiles de PM2 
# Ver estado
pm2 status

# Ver logs en tiempo real
pm2 logs reclutalia-pr-bot

# Reiniciar
pm2 restart reclutalia-pr-bot

# Detener
pm2 stop reclutalia-pr-bot

# Que arranque al reiniciar la Mac
pm2 startup
pm2 save

8. Solución de problemas

El bot no responde en Telegram

  • Verifica que el bot sea admin del grupo
  • Verifica que el TELEGRAM_CHAT_ID sea correcto
  • Si usas topics, verifica el TELEGRAM_TOPIC_ID
  • Revisa los logs: pm2 logs reclutalia-pr-bot

Error "No estás autorizado"

  • Tu username de Telegram debe estar en TELEGRAM_AUTHORIZED_USERS
  • El username es sin @ y case-insensitive
  • Después de editar el .env, reinicia el bot

Error de login en AWS

  • Verifica usuario y contraseña en el .env
  • Si cambió tu contraseña de AWS, actualiza el .env y reinicia
  • Borra aws_session.json para forzar un login limpio

Error "Navigation interrupted"

  • Es intermitente (~5% de los PRs). El bot ya tiene retry automático.
  • Si falla, simplemente vuelve a aprobar el PR en Telegram.

El bot se queda "procesando" y no avanza

  • Reinicia: pm2 restart reclutalia-pr-bot
  • Si persiste, borra aws_session.json y reinicia

Quiero ver qué hace el browser

Cambia en .env:

HEADLESS=false

Reinicia el bot y verás el browser de Chromium abrirse y navegar.
