3. Configurar Telegram

3.1 — Crear el bot

1Hablar con @BotFather

En Telegram, busca @BotFather y envía /newbot.

Te pedirá nombre y username. El username debe terminar en "bot".

BotFather te dará un token: 7123456789:AAH... → Guárdalo.

3.2 — Crear grupo y agregar el bot

2Grupo de Telegram
  • Crea un grupo nuevo (ej: "PR Autorización")
  • Agrega tu bot al grupo
  • Hazlo administrador (necesita leer y enviar mensajes)

3.3 — Obtener Chat ID del grupo

3Chat ID

Envía un mensaje en el grupo, luego abre en tu navegador:

https://api.telegram.org/bot<TU_TOKEN>/getUpdates

Busca "chat":{"id":-100XXXXXXXXXX}. Ese número negativo es tu TELEGRAM_CHAT_ID.

3.4 — (Opcional) Topic ID

Si usas Topics en el grupo:

  • Envía mensaje en el topic deseado
  • En getUpdates busca "message_thread_id": 205
  • Ese es tu TELEGRAM_TOPIC_ID

3.5 — Tu User ID

4User ID

Habla con @userinfobot en Telegram. Te da tu ID numérico → TELEGRAM_OWNER_USER_ID

3.6 — Usuarios autorizados

Solo los usuarios en TELEGRAM_AUTHORIZED_USERS pueden aprobar/rechazar PRs.

Pon los usernames de Telegram sin @, separados por coma:

TELEGRAM_AUTHORIZED_USERS=juanalva997,JcLievano,gabrielbarba28

USER_PROFILES — Formato

Cada perfil tiene 3 campos separados por : y los perfiles se separan por ,

USER_PROFILES=username1:Nombre Completo:email@empresa.com,username2:Otro Nombre:otro@empresa.com

Ejemplo real:

USER_PROFILES=juanalva997:Juan Alva:juan@empresa.com,jclievano:Juan Carlos:jc@empresa.com
Los usernames deben coincidir con los de TELEGRAM_AUTHORIZED_USERS (case-insensitive).

ROLE URLs — Cómo obtenerlas

En la consola de AWS, ve a "Switch Role" y copia la URL. El formato es:

https://signin.aws.amazon.com/switchrole?roleName=NOMBRE_ROL&account=ALIAS_CUENTA
Nunca compartas tu .env. Está en .gitignore y no se sube al repo.

5. Ejecutar el bot

1Compilar y ejecutar 
npm run start

Deberías ver:

🚀 Iniciando bot de PR Autorización...
[WS] Servidor WebSocket iniciado en puerto 9876
🤖 Bot de Telegram iniciado, escuchando mensajes...
✅ Bot corriendo. Presiona Ctrl+C para detener.
Si ves ese mensaje, el bot está funcionando. Pega una URL de PR en el grupo para probar.

Primera vez: MFA

La primera vez te pedirá MFA por DM en Telegram:

  • Ten tu app de MFA lista (Google Authenticator, etc.)
  • Responde con los 6 dígitos cuando el bot te escriba
  • Que el código tenga al menos 20 segundos antes de expirar

Después guarda la sesión y no vuelve a pedir MFA hasta que expire.

6. Cómo usar el bot

Flujo normal

  1. Alguien pega una URL de PR de CodeCommit en el grupo
  2. El bot envía botones: ✅ Aprobar / ❌ Rechazar
  3. Un usuario autorizado hace click en ✅
  4. El bot procesa (approve con 2 roles + merge) automáticamente
  5. Reporta resultado en el grupo

URLs aceptadas

El bot detecta URLs de CodeCommit con cualquier tab:

https://us-east-1.console.aws.amazon.com/codesuite/codecommit/repositories/REPO/pull-requests/12345/details?region=us-east-1
https://us-east-1.console.aws.amazon.com/codesuite/codecommit/repositories/REPO/pull-requests/12345/commits?region=us-east-1
https://us-east-1.console.aws.amazon.com/codesuite/codecommit/repositories/REPO/pull-requests/12345/changes?region=us-east-1

Comandos

ComandoQué hace
/statusEstado del bot + cola
/queuePRs en cola
/logÚltimos 5 PRs procesados
/pr <url>Agregar PR manualmente

Aprobar por texto

  • si — aprueba (si solo hay un PR pendiente)
  • si #29540 — aprueba PR específico
  • no — rechaza

3Comandos útiles

pm2 logs reclutalia-pr-bot

# Reiniciar
pm2 restart reclutalia-pr-bot

# Detener
pm2 stop reclutalia-pr-bot

# Que arranque al reiniciar la Mac

pm2 save

8. Solución de problemas

El bot no responde en Telegram

  • Verifica que el bot sea admin del grupo
  • Verifica TELEGRAM_CHAT_ID
  • Si usas topics, verifica TELEGRAM_TOPIC_ID
  • Logs: pm2 logs reclutalia-pr-bot

"No estás autorizado"

  • Tu username debe estar en TELEGRAM_AUTHORIZED_USERS
  • Sin @, case-insensitive
  • Reinicia el bot después de editar .env

Error de login AWS

  • Verifica usuario/contraseña en .env
  • Si cambió tu password, actualiza y reinicia
  • Borra aws_session.json para forzar login limpio

"Navigation interrupted"

  • Es intermitente (~5%). El bot reintenta automáticamente.
  • Si falla, vuelve a aprobar el PR.

Se queda "procesando" y no avanza

  • pm2 restart reclutalia-pr-bot
  • Si persiste, borra aws_session.json y reinicia

Quiero ver el browser

HEADLESS=false

Reinicia y verás Chromium navegando.
